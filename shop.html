Quick-add workflow for Callie

  1. Drag watermarked PDF + demo audio files into assets/shop/templates/.
  2. Match names by slug (example: moonrise.pdf + moonrise-demo.mp3).
  3. Add one item object in shop-items.js (title, category, description, pdf, audio).
  4. Refresh: the card appears automatically with preview/download links.
